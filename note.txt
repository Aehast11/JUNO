 Known Limitations
Due to the constraints of the VEX V5 screen API, which does not currently support custom font scaling, there may be minor inconsistencies in text placement.
'If you discover a workaround or a more optimized layout for these elements, contributions and suggestions are welcome.

 Project Information
This interface was originally developed for Team 9494A and our robot, Juno. Please keep the following in mind:

Customization: This code is intended as a reference for your own custom interface. You are encouraged to modify the design to suit your team's specific needs.

Functionality: Please note that this repository currently contains the UI code only. It does not yet include robot control logic or driver configurations.

Attribution: You are welcome to use or adapt this design in your own projects; however, we kindly request that you provide appropriate credit to the original creators.
